# MyMovies-Arabic

مستودع مستقل لإضافات Cloudstream. المصدر الأول المخطط له: Movix.

## الحالة الحالية
- تم تجهيز هيكل المستودع وملف تعريف Cloudstream.
- لم يتم اعتماد أو تنفيذ محلل تشغيل لموقع Movix بعد؛ تعذر التحقق من HTML/API للموقع.
- لن يتضمن المشروع استخراج روابط بث غير مصرح بها. يمكن ربط مصادر تملك حق استخدامها أو خادمك الشخصي.

## إضافة المستودع إلى Cloudstream
بعد نشر المستودع وإعداد فرع `builds`:
`https://raw.githubusercontent.com/USERNAME/MyMovies-Arabic/builds/repo.json`

## البناء
هذا الهيكل يحتاج إلى استكماله باستخدام قالب Cloudstream الرسمي قبل بناء ملف `.cs3`.
راجع:
https://github.com/cloudstream3/plugin-template
